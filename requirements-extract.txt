# 動画モード（RVM: Robust Video Matting、extract.pyのrvm-mobilenetv3）は、
# RVM公式のONNXエクスポート済みモデルをダウンロードしonnxruntimeで実行するため、
# 追加の依存は不要（onnxruntimeは上のrembgの依存として既に入っている）。
#
# 当初はRVM本体（PeterL1n/RobustVideoMatting、MIT license）のモデルコードを
# torch.hub経由で取得しtorch/torchvisionで実行する方式にしていたが、実Actionsジョブ
# での検証で以下の問題を確認したため、ONNXエクスポート済みモデルを直接使う方式に
# 変更した（詳細はextract.pyのRVM_ONNX_URL周辺のコメント参照）：
#   - RVM本体はtorchvision.models.mobilenetv3の非公開の内部クラスに直接依存しており、
#     torch==1.9.0/torchvision==0.10.0（2021年）でのみ動作確認されている。最新の
#     torch/torchvisionと組み合わせるとアルファが常に0になる不具合があった
#   - Python 3.12に対応する範囲で近いバージョン（torch==2.2.2/torchvision==0.17.2）に
#     固定しても、今度はtorch==2.2.2とNumPy 2.x系のABI不整合で動かなかった
# ONNXエクスポート済みモデルは固定済みの計算グラフのため、これらのモデルコード側の
# バージョン依存問題が構造的に発生しない。
